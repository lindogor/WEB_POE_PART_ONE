# Content Research: Sourcing Methodology

## 1. Organisation's own website
Used as the starting point for factual claims about A33 (location, three-floor concept, gadget-free floors). See `01-organisation-overview.md` for details and citations.

## 2. Social media / third-party listings
A public business-directory listing for A33 was used to cross-check the address, general opening hours and the description of the space, since the organisation's own site could not be fully crawled for this research phase. This listing also supplied incidental, non-essential colour (e.g. a staff member being mentioned by reviewers) that was **not** used in the final site copy, as it could not be verified directly with the organisation.

## 3. Public domain / Creative Commons resources
No third-party photography, icon sets or fonts have been embedded in the initial HTML build. Instead:
- All imagery placeholders in the HTML use CSS-generated patterns (`.placeholder-img`) rather than downloaded stock photography, to avoid any copyright or licensing ambiguity at this stage of the project.
- Typography uses system/web-safe font stacks (Georgia for headings, a standard sans-serif system stack for body text) rather than a licensed font, so no font licensing is required for this build.
- Before final submission, any photography used should be sourced from Creative Commons–licensed or purchased stock libraries (e.g. Unsplash, Pexels) or original photography supplied by A33, with attribution recorded here.

## 4. Original content
The following content was written originally for this project rather than copied from any source:
- All homepage, About, Menu & Gallery, Enquiry and Contact page copy
- The coffee menu item names and descriptions
- Team role descriptions
- Enquiry form field structure and labels
- Product/shop item names and descriptions
