# Changelog

All notable changes to the A33 website project are recorded here, most recent first.

## [0.1.0] — 2026-08-14
### Added
- Initial project structure: `index.html`, `about.html`, `services.html`, `enquiry.html`, `contact.html`.
- Shared stylesheet (`css/style.css`) with a terracotta/cream/charcoal palette, responsive layout and mobile navigation.
- Shared script (`js/script.js`) for mobile nav toggle, active-link highlighting and enquiry form validation feedback.
- Enquiry form on `enquiry.html` covering event bookings, exhibition enquiries and product/shop orders.
- Contact page with embedded map and contact form.
- Content research documentation in `/content-research`.
- Visual sitemap in `/docs/sitemap.svg`.
- Project README with full project overview, goals, timeline and file structure.

### Notes
- Menu items, prices, team bios and current exhibition details are illustrative placeholder content pending confirmation from A33 directly (see `content-research/01-organisation-overview.md`).
- Image placeholders use CSS patterns rather than downloaded photography to avoid licensing issues at this stage; real/licensed imagery to be added in a later phase.
